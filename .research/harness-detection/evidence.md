Every claim below carries its source and the date it was checked. "Direct experiment" rows name the
tool and version they ran against; they were run on Linux (WSL) from inside a Claude Code session,
so a nested CLI's child environment also carried Claude Code's variables (E-CODEX-D12). Environment
dumps recorded variable names only.

Confidence: **High** means a vendor page states it, or a direct experiment or source read shows it
unambiguously. **Medium** means it is read from a shipped bundle or implied by a vendor page.
**Low** means the evidence is indirect.
